# DidaSync 使用指南

> 先同步任务，再选择适合你的笔记、规划或 AI 工作流。

## 5 分钟开始

1. 在 `设置 -> DidaSync -> OAuth` 完成授权。
2. 点击功能区 DidaSync 图标，或运行 **打开滴答清单**。
3. 运行 **手动双向同步**，确认任务已出现。

之后可在 `设置 -> 同步` 开启自动同步。需要立刻确认修改、首次使用或网络恢复后，使用手动同步。

## 同步并组织任务

**入口：** DidaSync 侧边栏，或命令 **打开滴答清单**。

在侧边栏中可以新建任务，修改标题、日期和完成状态；拖拽任务可调整顺序、设为子任务或移至其他清单。项目、子任务、日期、提醒和重复规则会随同步更新。

任务右侧的云朵表示本地记录是否已关联远端。离线时本地修改会保留；网络恢复后手动同步即可。

## 在 Markdown 中管理待办

**入口：** `设置 -> 同步 -> 启用原生任务同步`。

1. 在笔记中输入 `- [ ] 准备周报`。
2. 在操作菜单中创建滴答任务或关联已有任务。
3. 勾选 `- [x]` 后，关联任务会同步完成状态。

普通 Markdown 待办不会自动上传；只有完成创建或关联后，才会与滴答任务联动。

## 将任务写入笔记

**适合：** 日记、周记、计划和复盘。

**入口：** 命令 **同步任务到笔记**；路径和写入区块在 `设置 -> 同步 -> 任务写入笔记` 配置。

选择日、周、月、年或自定义范围，再选择清单来源。插件会将任务写入同名笔记，也可设置为每次生成新笔记。

若想在业务笔记中固定一个任务区域，可加入：

```md
> [!didasync] {"range":"2026-01-01~2026-01-31","projects":["工作"]}
```

`range` 支持单日或日期区间；`projects` 可填写清单名或 `id:<项目ID>`。

## 同步滴答笔记

**适合：** 将手机闪念或滴答 NOTE 带回 Obsidian。

**入口：** `设置 -> 同步 -> 启用滴答笔记同步`。

1. 设置保存位置，并选择参与同步的清单。
2. 点击 **同步笔记**，或运行 **同步滴答笔记到 Obsidian**。
3. 每条 NOTE 会保存为一个 Markdown 文件；编辑本地内容后再次同步，可更新远端内容。

只处理选中清单中类型为 NOTE 的记录。它与“任务写入笔记”不同：前者同步笔记内容，后者汇总任务。

## 安排、回顾与专注

- **时间块**：在侧边栏切换到时间段视图，安排任务时段；视图设置可调整起始时间和每小时高度。
- **时间线日历**：桌面端入口，适合按日/月/年查看任务分布和完成情况。
- **番茄钟**：桌面端入口，支持专注与休息时长；记录仅保存在本地专注统计中。

## MCP / AI（桌面端）

**入口：** `设置 -> DidaSync -> MCP`。

启用服务后复制 token，并将本机地址、token 和时区配置到兼容 MCP 的 AI 工具。首次建议开启 **只读模式**；确认权限范围后，才允许 AI 创建、修改、完成、删除或同步任务。

MCP 服务只监听 `127.0.0.1`。不要公开 token。

## 常见问题

### 授权失败或回调没有反应

确认回调端口未被占用，且插件设置中的回调地址、端口与滴答开发者后台的 redirect URL 一致。Windows 异常时可改用 `127.0.0.1`；移动端可粘贴浏览器授权得到的 `code`。

### 数据看起来不对

先手动同步并检查网络和授权。仅在确定要重新从云端获取本地缓存时，才使用 `设置 -> 高级 -> 重置任务数据`；该操作会清空本地任务缓存。
